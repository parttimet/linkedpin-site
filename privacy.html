Privacy Policy – LinkedPin Automation

Last updated: 17 October 2026

LinkedPin Automation is a private tool used only by the LinkedPin YouTube channel. It is not offered to the public and collects no data from visitors or viewers.

Data accessed

With the channel's permission (Google OAuth), it accesses only the LinkedPin channel's own YouTube data: its videos, captions, playlists, comments and YouTube Analytics reports.

Use

Only to upload and manage LinkedPin's own videos and review the channel's own performance. Data is not sold, shared with third parties or used for advertising.

Storage and revocation

Access tokens and reports are stored privately and never published. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Contact: via the LinkedPin YouTube channel.
